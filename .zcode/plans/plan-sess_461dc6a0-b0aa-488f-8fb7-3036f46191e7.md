# 批量处理队列实现计划

## Context

当前 App 与 CLI 一次只能处理一个视频文件。Core 管道 `DlssVideoPipeline.RunAsync` 是静态单文件入口，进程级 `PipelineGate`（SemaphoreSlim(1,1)，因 NGX 宿主为进程级单例）已保证顺序调用多个文件天然安全，RIFE 会话还有跨文件缓存复用。因此批量 = **UI/CLI 层新增队列编排，Core 不动**。

已确认的需求：统一队列模式（单文件=队列一项，设置整批共用）；单项失败标记后继续下一项；取消=中止当前项+剩余标「已跳过」；队列项基础操作（移除、清空已完成，输出自动命名 `原名_dlss5.ext` 冲突自动加后缀）；CLI 一并支持多文件/目录。

## 改动文件

### 1. 新增 `src/Dlss5Demo.App/TranscodeQueueItem.cs`（~100 行）

- `enum QueueItemState { Waiting, Running, Done, Failed, Cancelled, Skipped }`
- `sealed class QueueItem : INotifyPropertyChanged`（手写最小 INPC，项目无 MVVM 框架）：`InputPath`、`OutputOverride`（用户指定的输出，可空）、`ActualOutput`、`Video`（探测结果）、`State`、`StatusText`、`Detail`（探测/结果信息）、`StatusGlyph`（●/▶/✓/✗/−）、`StatusBrush`（`ImmutableSolidColorBrush`，随状态更新）
- 探测与结果统计的更新方法（`SetProbeResult` / `SetRunning` / `SetDone` / `SetFailed` / `SetSkipped`）

### 2. 修改 `src/Dlss5Demo.App/MainWindow.axaml`

- **Row1 输入栏重构为队列面板**：工具行（`添加视频` 按钮 `AddButton`、`清空已完成` 按钮 `ClearFinishedButton`、队列摘要 `QueueSummaryText`）+ `ListBox x:Name="QueueList"`（MinHeight 100 / MaxHeight 180，DropArea 拖放提示空态 TextBlock）。项模板：状态圆点（Ellipse Fill 绑 StatusBrush）+ 文件名（ToolTip 全路径）+ StatusText + 移除 `×` 按钮（Click 事件，经 `((Button)sender).DataContext` 取项）
- 左列「源视频」卡片改为「选中项详情」：`InfoText`/`HdrSourceText`/`OutputBox` 语义变为当前选中队列项（OutputBox 保留可编辑=该项自定义输出，留空则自动命名；「另存为」「打开输出目录」沿用）
- 操作面板：StartButton 文案不变（开始转码）；`Progress`/`StatusText` 仍为当前项进度；**新增一行 `QueueStatusText`**（"队列 2/5 · 成功 1 · 失败 0"）

### 3. 修改 `src/Dlss5Demo.App/MainWindow.axaml.cs`（核心重构，~250 行变更）

- 字段：`ObservableCollection<QueueItem> _queue`（QueueList.ItemsSource）、`QueueItem? _runningItem`；删除 `_video`/`_probeGeneration`/`_suggestedOutputPath`（探测结果挂到 QueueItem 上）
- `AddFiles(IEnumerable<string>)`：File.Exists + 扩展名过滤 + 与现有项去重 → 入队 → 每项 `Task.Run(MediaProbe.Probe)` 异步探测写回 item（守 `_closed`）；`Browse_Click` 改 `AllowMultiple=true`；拖放 `GetDroppedVideoPath` 改复数版收集全部视频文件；`DLSS5_INPUT` 环境变量改为入队一个
- `RemoveItem_Click`：Running 项不可移；`ClearFinished_Click`：移除 Done/Failed/Cancelled/Skipped 项
- `QueueList.SelectionChanged` → 详情卡显示选中项探测信息/输出路径（`_updatingOutputBox` 旗标防 TextChanged 回写循环）
- `Start_Click` 重构：校验「队列含 Waiting 项」（探测失败的项也允许跑，由管道报错标 Failed，不卡整批）→ `NrRuntimeCatalog.Resolve` 一次 → **快照全部设置**（CollectVideoOptions/DlssOptions/超分/Quality/MaxFrames 等，整批生效并 Log 说明）→ 等待上一 `_pipelineTask`（保留现有 NGX 串行等待逻辑）→ `_pipelineTask = RunQueueAsync(snapshot, token)` 并 await
- 新增 `RunQueueAsync`：循环取下一个 `State==Waiting` 项（运行中新添加的文件自然被捡到）→ 逐项：State=Running、`ResetPreview()` + 新建 `TranscodePreviewBuffer`、输出路径（OutputOverride 或 `OutputFileNames.ForInput` + `Available`）、`TranscodeOptions`（快照 + 每项 PreviewSink，record 可 `with`）→ `await DlssVideoPipeline.RunAsync(..., progress, token)`；成功→Done+统计文本；`OperationCanceledException`→当前项 Cancelled、剩余标 Skipped、退出循环；其他异常→Failed+Log+**继续下一项**；每项结束更新 QueueStatusText/QueueSummaryText；结尾汇总 Log「队列完成 · 成功 X · 失败 Y · 跳过 Z」。沿用 `_runGeneration` 守卫防旧队列写新 UI
- `CancelButton` 语义：取消整个队列（队列级 CTS）；`CompareButton`/`_lastOutputPath` = 最近完成项实际输出；`OpenVideoFolderButton` 打开选中项源目录

### 4. 修改 `src/Dlss5Demo.Cli/Program.cs`（~80 行变更）

- 参数解析重写：**所有非 `--` 位置参数 = 输入列表**（目录则枚举内含支持扩展名视频并排序展开）；flag 解析从 `for index=2; index<args.Length-1` 改为全量扫描（顺带消除现有边界隐患）；新增 `--output`（单输入指定输出）、`--output-dir`（多输入输出目录，默认源文件同目录）
- ⚠️ **Breaking**：旧用法 `cli input output`（第二个位置参数为输出）不再支持，第二个位置参数一律视为第二个输入文件
- 循环逐个 `RunAsync`：进度行加文件名前缀；单项失败打印错误继续；`Console.CancelKeyPress` 接队列 CTS（Ctrl+C→当前项取消、剩余跳过）；结尾打印汇总（成功/失败/跳过 + 总耗时）；`ReleaseGpuResources()` 保持在最后
- 批量输出扩展名按 encoder 映射（含 gif→`.gif`，否则 `.mp4`），冲突走 `OutputFileNames.Available`

不改动：Core 全部、`AppSettings`（无新设置项）、`Autorun.cs`（保持单文件自动化入口）。

## 验证

1. **构建**：`dotnet build Dlss5VideoEnc.sln -c Debug -p:Platform=x64`（注意本项目 `<Platforms>x64</Platforms>` 陷阱，产物在 `bin\x64\Debug\`，跑前确认 exe 时间戳）
2. **CLI 批量冒烟**（真实 GPU 管线）：用 ffmpeg 生成第二个小视频（`testsrc` 5s 1080p），跑 `Dlss5TestCli <测试视频> <小视频> --frames 30 --nr 0`，验证：顺序处理、自动命名两个输出无覆盖、汇总统计；再测一个不存在的输入混入队列 → 该项 Failed 但另一项照常完成
3. **Ctrl+C**：CLI 批量运行中发取消，验证当前项中止、剩余标跳过、汇总正确
4. **App 冒烟**：设 `DLSS5_INPUT` 启动 App 验证入队路径正常、窗口无异常；完整 UI 交互（多选添加、拖放多文件、移除、清空已完成、选中详情、运行中追加文件）由你手动验收
5. App 队列跑两个文件（勾选「仅处理前 60 帧」）验证 UI 逐项状态流转与预览切换
