## 第二次修复：Stage 命令退出码 1（编码坑）

- **根因**：`tools/package.ps1` / `package-msix.ps1` 是 UTF-8 **无 BOM**；VS 的 Stage 用 `powershell.exe`（WinPS 5.1），5.1 按 GBK 解码无 BOM 的 UTF-8 脚本 → 中文注释/字符串乱码并产生 6 / 7 处语法错误 → 脚本一行未执行 → 退出码 1。诊断证据：`artifacts/msix/payload` 时间戳/内容完全未变；用 `[Text.Encoding]::GetEncoding(936).GetString(bytes)` + `Parser::ParseInput` 模拟 5.1 解码可精确复现这些错误。
- 修复：两个脚本改为 UTF-8 with BOM（PS7 同样兼容）；`$OutputRoot.TrimEnd('\','/')` 改为 `$OutputRoot -replace '[\\/]+$',''`；wapproj 注释与 README 明确写入「含中文的 tools/*.ps1 必须带 BOM」。
- **教训**：PS7 默认 UTF-8 读无 BOM 脚本，所以之前用 PS7 工具端到端验证通过并不代表 VS 的 5.1 能跑。凡是被 wapproj 的 `Exec` 调用的脚本，必须用 5.1 实测（可用 `& 'C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe' -File ...`），或用 GBK 解码 + ParseInput 模拟。
- 验证：WinPS 5.1 实跑 `package.ps1 ... -AllowGenericFfmpeg` 退出码 0，中文警告正常，产出完整负载；5.1 模拟解析 0 错误；XML / PS1 语法 / `git diff --check` 通过。

## 第三次修复：VS 签名失败 `0x800700C1`（同日追加）

- **根因**：VS 报「未能对 … 签名 / Done Adding Additional Store」；用 `signtool sign /debug` 复现得到 `SignedCode::Sign returned error: 0x800700C1`（ERROR_BAD_EXE_FORMAT）。设置 `APPXSIP_LOG=1` 后定位到 `Dlss5Demo.App\runtime\nr\Community-SF-v2-310.8-RTX20-RTX30-Series\nvngx_dlssnr.dll` 的 `File has malformed certificate`。PE 分析：Security Directory 偏移 165830144 = 文件长度，却声明 10352 字节证书，即签名被裁剪。AppxSip 为包内所有 PE 生成代码完整性目录时拒绝整包签名，与证书指纹/有效期/Publisher 无关（该指纹对应证书有效、有私钥、EKU 含代码签名）。
- **修复 A（负载）**：`tools/package.ps1` 新增 `Clear-BadPeCertificateDirectory` / `Repair-MalformedPeCertificates`，扫描负载内 PE，只有目录项明显非法时才把 8 字节 Security Directory 清零（等价于未签名），合法签名不动；只改负载副本，`runtime\` 源文件不变；在生成 `SHA256SUMS.txt` 前执行。WinPS 5.1 实跑只命中 1 个文件。
- **修复 B（包体翻倍）**：`InjectMsixPayload` 原来把多个 `Filename=Dlss5VideoEnc` 项的 `TargetPath` 用 `;` 连接后传给 `GetDirectoryName`，产生含分号前缀 → 托管负载没被移除 + 注入 `%3B` 乱码路径 → 536 条目 / 3.13 GB 未压缩 / 1.95 GB 成包。改为 `WithMetadataValue('Extension','.exe')` + `Regex::Replace(';.*$','')` 取首个 exe，并对含分号前缀 `Error`。用 `dotnet build artifacts/msix/verify-prefix.proj` 实测得到 `Dlss5Demo.App\` 且 4 个托管项全部匹配移除。
- 其它：`GenerateTemporaryStoreCertificate=false`（避免每次打包往 `Cert:\CurrentUser\My` 追加一次性证书，本机该 Subject 已有 2151 张、71 张过期）；`package-msix.ps1` 新增 `-PayloadDirectory`，`-CreateTestCertificate` 过滤有效期/私钥。
- **端到端验证**：WinPS 5.1 跑 `package.ps1 -OutputName payload-pecheck` → `package-msix.ps1 -SkipStage -PayloadDirectory ... -Version 1.1.1.0` 出包 281 条目 / 990.8 MB → `signtool sign /fd SHA256 /sha1 0002A085…` 与 `verify /pa` 均退出码 0。产物 `dist/Dlss5VideoEnc_1.1.1.0_x64.msix`（已签名，但用的是通用 FFmpeg，仅供本地调试）。
- **诊断手法沉淀**：MSIX 签名失败先用 `APPXSIP_LOG=1` 再跑一次 signtool；`0x800700C1` → 包内 PE 证书目录损坏；`0x8007000B` → Publisher 与证书 Subject 不匹配。
