## Fluent UI 重构 + 设置页 DLSS NR 运行库目录（Dlss5TestDemo）

- 界面重构为 `FAAppWindow` + `FANavigationView`（工作台 / 设置两页常驻，切页不重建工作台状态）；旧 `src/Dlss5Demo.App/MainWindow.axaml(.cs)` 删除，逻辑迁入 `Views/WorkbenchView.axaml(.cs)`；新增 `Views/SettingsView.axaml(.cs)`、`Views/Themes/CommonStyles.axaml`、`Views/Controls/ToolPageHeader`、`Views/Controls/StatusPill`。
- 新增 `AppSession`（App 层）：设置单实例、主题应用、NR 目录变更广播、`IsProcessing`；`AppSettings` 增加 `ThemeIndex`（默认 2 深色）与 `NrRuntimeDirectory`。
- Core 新增 `NrRuntimeLocations`（进程级用户目录，等于 runtime 视为默认）与 `NrRuntimeMigration`（逐个复制 + SHA-256 校验后删源；相同文件去重；同名冲突改名为 `name (2).dll`；只读目录保留源文件；只清理因迁移变空的目录）。`NrRuntimeCatalog.Discover` 增加 `custom/` 前缀条目；`DemoPaths` 自动链改为 env → mods → 用户目录 → runtime，空用户目录不再触发显卡代际探测。
- 设置页 NR 卡片：打开 / 更改…（迁移确认 + 字节进度 + 取消）/ 迁移内置运行库到此目录 / 恢复默认 / 刷新列表；迁移后把保存的 `NrRuntimeId` 从 `runtime/` 或旧 `custom/` 重映射到新 ID。切换目录“先落盘再迁移”，避免文件搬走但设置仍指旧目录。
- 验证：`dotnet run --project tests/Dlss5Demo.Tests` 31 项通过（新增 `NrMigrationTests` 3 项）；`dotnet build Dlss5VideoEnc.sln`（Debug/Release）0 错误，仅有 wapproj 的预期 NU1503；真实启动日志出现 `NR 使用设置页指定的运行库目录`，关闭时 settings.json 写入新字段；深/浅两套主题截图核对，修掉预览卡纵向溢出与导航默认折叠。
